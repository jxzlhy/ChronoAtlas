# PROJECT CONTEXT · 项目背景与设计决策

## 起源

复刻抖音 @Cyber航说 的 VibeCoding 作品《24小时，我用智能体做了一个3D历史地图》：3D 地球 + 发光棱柱呈现 1750–1911 历史事件，配双语事件卡、时间轴、搜索与大洲导航。本项目为独立复刻与再创作（纯前端，无后端），并按"无限自主迭代协议"持续演进。

## 产品定位

"站在太空看历史"——把抽象年代变成可旋转、可切片、可探索的空间直觉。核心三件套：拖地球（空间）、拖时间轴（时间）、点棱柱（内容）；V0.4+ 加持下时间轴成为"切片器"，V0.5+ 因果长河让事件连成时代叙事。

## 关键设计决策

| 决策 | 理由 |
|---|---|
| 原生 Three.js 而非 R3F | 纯 3D 应用无 UI 树复用需求，更轻更快 |
| zustand vanilla | 单向数据流：store → UI/场景，无 React 依赖 |
| 数据内置（119 条） | 零部署依赖；>300 再考虑分包/后端 |
| 棱柱 = 常亮地块 + 窗口内棱柱 | "历史无处不在" + 时间切片戏剧性 |
| 相机 slerp | 北极恒朝上，路径自然 |
| 贴图三源降级 + 线框兜底 | 外链不可用时功能不损 |
| 全双语 | 对齐原视频气质，扩大受众 |
