# ChronoAtlas V2 阶段方案（通宵迭代定稿 · 2026-11-13）

## 现状审计（方案依据）

已完成：V1.0.0 发布 + 16 个增量。数据 137 事件（来源/文明/imp3 双保险全 100%）· 关系 52（100%）· 人物 52（100%+档案七节）· 航线 5 · 离线 PWA · URL 五参数 · 40 项 QA 断言。技术债为零重大项（drawCalls 29、无泄漏报告）。

**V2 核心判断**：单年切片模式已到体验天花板。用户能看"1850 年的世界"，但不能看"1848–1871 这段如何演变"。V2 的主线应是——**从"切片"到"段落"：时间跨度叙事（Time Span Narrative）**。这不需要新数据，是对现有 137 事件 + 52 关系的重组利用，ROI 最高。

## V2 三支柱

### V2.1 时间跨度模式（本通宵执行）
- 时间窗口从 ±5/±10/±20/全部 扩展为"时代视角"：选择时代波段后，时间轴自动定位该时代并锁定窗口为其起止
- 快照面板标题显示"时代视角：民族之春与统一（1848–1871）"
- 密度条高亮当前时代区间（非时代段降低透明度）
- 事件来源双保险展示已在 V1.7 完成

### V2.2 人物时代轨迹深化
- 人物卡时间线按 eraOf 分组（人物各事件归入时代波段）
- 人物时代入口点击已有（V1.3），补"时代内人物"反向查询：时代 chips hover 显示该时代活跃人物数

### V2.3 文明面板深化
- 文明对比视图（已做）叠加时代维度：同一文明跨时代事件分组
