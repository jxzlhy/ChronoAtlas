优先级铁律：历史真实性 > 数据数量；产品完整性 > 功能数量；交互质量 > 装饰效果；稳定性 > 炫技；性能 > 不必要特效。

## 3. PHASE A — DATA INTEGRITY（P0）

- A1 统一数据模型：EventLink 增加可追溯来源；Person 来源规范化；关系审核状态规范化；引用规则明确；禁默认值伪造。按需引入实体（人物关系/地点/历史路线/文明/时期）——不引入无使用场景的复杂模型。
- A2 真实性审查：逐条核查事件/关系/人物/来源；时间先后 ≠ 因果；关联 ≠ 亲自参与；不为数量制造因果。
- A3 来源体系：Britannica/UNESCO/LoC/Smithsonian/British Museum/Met/Europeana/World History Encyclopedia 等；可信度分级；重要事件多独立来源；禁仅验域名即当验证；Wikipedia 不可作唯一证据。
- A4 校验系统：唯一性/端点有效性/来源引用（事件·人物·关系）/时间坐标异常/双语/审核状态/重复/孤立人物/数据质量报告（覆盖率、reviewed 比例、pending、无来源计数、孤立节点、双语完整率），命令可重复生成。
- A5 扩容：女性、奥斯曼、拉美、非洲、东亚、南亚、大洋洲、科学史、贸易经济史、思想宗教文化传播；每次检查地理与时间分布，避免欧洲过度集中。

## 4. PHASE B — HISTORICAL JOURNEYS（P0，本轮最重要新产品能力）

- B1 路线数据模型：ID/双语名/类型（航海探险·陆上探险·商贸·迁徙·军事·科学考察·文化传播·地理发现）/时期/起点终点途经点/坐标/时间范围/相关人物事件/来源/审核状态/说明/背景。区分：历史路线、人物活动轨迹、事件关系弧线——三者不得混用。
- B2 第一批路线（史料充分）：丝绸之路、郑和下西洋、哥伦布航行、麦哲伦环球、库克探险、维京远航、大航海航线、古代贸易网络、迁徙路线、科学考察。争议段明确标记不确定性；不编造途经点。
- B3 3D 动态路线：逐段绘制/方向指示/节点/起终点标记/进度动画/时间控制/高亮/摄像机跟随/自由旋转/播放暂停重置/事件联动。跨日期变更线正确插值；避免直线穿地球内部/背面错误显示。
- B4 路线探索面板：名称/背景/起止时间/类型/关键人物/关联事件/距离（可靠才展示）/途经点/来源/进度；点击地点-人物-事件联动；切换平滑。
- B5 路线叙事模式：纪录片式——按历史时间推进、停靠点展示、事件联动、人物介绍、来源；自动播放+手动推进+暂停+跳节点+退出+随时接管摄像机；中英文。

## 5. PHASE C — HISTORICAL FIGURE ATLAS（P1）

- C1 活动轨迹：出生/生活/活动/旅行/事件/逝世地点，各含坐标/时间/事件/来源/精度；推测不当准确；不伪造连续路径。
- C2 人物关系网络：师生/家族/政治合作/对立/学术影响/思想传承/同时代关联；类型明确；区分直接与影响；不同时代不硬连。
- C3 完整档案：生平/贡献/时间线/活动地图/关联事件/人物关系/背景/参考资料；与地球/时间轴/事件联动。
- C4 探索路径：人物→事件→地点→其他人物→时期连续探索。
