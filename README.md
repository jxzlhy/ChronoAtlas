# ChronoAtlas · 动态历史地球 — THE LIVING HISTORY

> **V1.0** · 137 条双语历史事件 · 52 条因果链 · 52 位人物 · 5 条历史航线 · 全部来源人工验证


在 3D 地球上探索公元 **1750 – 1911** 年的世界历史事件。拖动地球、滑动时间轴，看六棱柱在各大洲升起；点击棱柱阅读双语事件卡，沿"历史长河"追溯因果，搜索任意事件、人物或地点，一键飞越大洲。

> 灵感来源：抖音 @Cyber航说《24小时，我用智能体做了一个3D历史地图》（VibeCoding大赏）。本项目为其独立复刻与再创作。

**规模**：137 条双语事件 · 52 条因果链（六类关系） · 51 位双语人物（11 位有活动地图） · 41 条已验证参考资料 · 5 条历史航线 · 七类事件体系

## 快速开始

```bash
npm install
npm run dev            # http://127.0.0.1:5173
npm run typecheck      # tsc --noEmit
npm run validate:data  # 数据完整性校验 + 数据画像
node scripts/verify.mjs   # 无头 Chrome 端到端验证（17 步，自带 dev server 自愈）
```

## 核心功能

| 功能 | 说明 |
|---|---|
| 3D 地球 | 真实 NASA 贴图（三源自动降级）+ 大气菲涅尔辉光 + Bloom 后期 + 星空 |
| 六棱柱事件层 | 按类型着色、按重要度定高，欠阻尼弹簧生长，选中呼吸脉冲 |
| 时间轴 1750–1911 | 渐变轨道拖动 / 事件密度条（点击跳年）/ 年代提示 / ▶ 自动播放（1×/2×/5×） / 时间窗口 ±5/±10/±20/全部 / ←→ 键微调 |
| **世界快照** | 年份驱动的时代切片：时代分期（六波段双语名+背景句）、类型/大洲筛选 chips（联动地球棱柱明暗）、四种排序、**同时代对比**（按大洲分节并置代表事件） |
| 双语事件卡 | 类型徽章、中英标题、中英描述、星级、定位按钮、参考资料外链、相关人物 |
| **历史长河** | 32 条因果链（六类关系，tooltip 标注类型）：前因紫/后果青 chips 沿链跳转，BFS 多跳发光弧线按类型着色，一跳/三跳可切 |
| **因果网络** | 二维网络视图：节点=事件（重要度定径、类型着色），连线=关系（六类着色），力导向布局，平移/缩放/拖拽，与地球共享选中状态 |
| **人物层** | 46 位双语人物：搜索直达、事件卡 chips → **人物档案卡**（双语简介/活动地区/人物时间线，行点击定位地球），URL `p=` 分享还原 |
| 搜索 | 中英模糊匹配事件+人物，`/` 聚焦，回车跳转 |
| 键盘快捷键 | `/` 搜索 · `←`/`→` 年份（Shift ±10） · `N` 因果网络 · `H` 热区 · `R` 随机发现 · `P` 世界快照 · `J` 历史航线 · `Esc` 关闭面板 |
| **历史航线** | 5 条有据路线（丝路/郑和/哥伦布/麦哲伦/库克）：逐段大圆绘制、叙事播放（相机跟随/拖动接管/节点跳转）、不确定性标注、人物事件联动 |
| URL 分享 | `#y=1850&ev=<id>&p=<人物>` 实时同步，刷新/分享精确还原 |
| 大洲定位 | 正北/全球/七大洲 ghost 按钮，球面 slerp 飞行，北极恒朝上 |
